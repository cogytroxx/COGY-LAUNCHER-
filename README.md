## 🚀 COGY LAUNCHER - Multi-Language Launcher

एक शक्तिशाली **लॉन्चर** जो Java, Kotlin, C, C++, और C# को सपोर्ट करता है।

### ✨ Features

- ✅ **Multi-Language Support**: Java, Kotlin, C, C++, C#
- ✅ **Beautiful GUI**: Swing-based interface
- ✅ **Easy to Use**: Simple click-based launching
- ✅ **Add/Remove Launchers**: Dynamic management
- ✅ **Launch Button** (दाईं ओर नीचे)
- ✅ **Add Button (+)** (LAUNCH के ऊपर)

### 🎨 UI Layout

```
┌─────────────────────────────────────┐
│        COGY LAUNCHER                │
├─────────────────────────────────────┤
│  [Java Program] [Path...] [Remove]  │
│  [Kotlin Script] [Path...] [Remove] │
│  [C Program] [Path...] [Remove]     │
│                                     │
│                     [+]   [LAUNCH]  │
└─────────────────────────────────────┘
```

### 🛠️ Compilation & Running

#### Java GUI
```bash
javac Main.java
java Main
```

### 📋 Usage

1. **Launch करें**: `java Main` (GUI को खोलता है)
2. **+ Button दबाएं**: नया launcher जोड़ने के लिए
3. **Language चुनें**: Java/Kotlin/C/C++/C#
4. **Path दें**: Program की path दें
5. **LAUNCH दबाएं**: सभी launchers एक साथ चलेंगे

### 💻 System Requirements

- **Java 8+**
- **Kotlin 1.5+** (optional)
- **GCC** (optional - for C/C++)
- **.NET SDK** (optional - for C#)
